# Security

This is development version 0.1.0, not a production monitoring service or a security boundary against malicious same-UID processes. The supported scope is the exact owned-fixture, serial-writer contract in docs/contract.md. Outside writers, network filesystems and hostile replacement of private ancestors are excluded.

Report suspected vulnerabilities privately through:

https://github.com/martinlofranodeoliveira/inotify-convergence-lab/security/advisories/new

Include a synthetic reproduction, affected version, actual environment information and the observed failure. Do not include secrets, private client code or real personal data. Do not test by scanning unrelated host files or attempting to overflow shared kernel resources. Simulated overflow is sufficient for the documented recovery test.

No response-time SLA is promised. General organizational contact is available at https://lofranotecnologia.com.br.
